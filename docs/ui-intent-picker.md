# 开发环境组件选择器

开发服务器启动后，点击右下角准星或按 `Cmd/Ctrl+Shift+X` 进入选择模式；`Esc` 退出。

- 悬停显示最近的业务组件名及匹配到的 CONTEXT.md 区域。
- 点击后，面板展示可展开的具名组件树，默认聚焦当前组件及最近三层祖先；祖先路径自动展开，其他分支（含库组件）默认折叠。`Show parent` 逐级扩大范围，`Show full tree` 展示完整快照。
- 点击名称选择组件，点击箭头展开或折叠；方向键可移动、展开和折叠，Enter/Space 选择。支持查看子组件、兄弟组件与 Portal 中的组件，隐藏普通 DOM 层及选择器自身。
- 选择节点会更新组件、源码位置及所属区域；复制内容采用所选分支的祖先链，单独保留原始点击元素和该位置的 testid，避免兄弟分支混用旧路径。
- 组件树是点击时的快照；页面结构变化后通过 `Pick again` 重新捕获。超出 20,000 个 Fiber 或 150 层组件时会显示限制提示，仍保留选中路径。
- 普通具名组件、函数上的 `displayName`、`memo` / `forwardRef` 外层的 `displayName` 自动识别，无需加入区域表。
- Astryx 组件通过对象身份识别；与其同名的本地组件不会被当作库组件跳过。默认选择业务组件，库组件仍可手动选择。

`apps/desktop/src/dev/ui-intent/regions.ts` 仅维护产品术语与组件的语义映射，不是组件选择白名单。新增区域绑定必须使用 CONTEXT.md 已定义的术语；非可视化领域概念不必强行映射。区域匹配沿 React 树从内向外检查组件及宿主元素属性，支持 Portal，避免外层大区域遮盖内层已标注区域。

选择器仅在开发环境挂载。源码位置仍依赖 React 开发模式 `_debugStack`；React 的 owner stack 预算耗尽时位置可能缺失，但具名组件仍可识别和选择。未由 React 渲染的第三方 DOM 不保证存在组件栈。

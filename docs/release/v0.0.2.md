# PiGUI v0.0.2

本次更新让你无需选择项目就能开始 Chat，并加入应用内更新、离线更新日志与更便捷的会话查找。

## 新增

- **免项目 Chat**：不必先选择代码仓库即可开始对话；侧栏独立管理 Chat，并可在设置中配置聊天工作区。支持工作区恢复和会话继续。
- **应用内更新**：在设置的 **About & Updates** 中检查、下载并安装后续版本；侧栏提供更新提示，macOS 应用菜单也提供检查更新入口。
- **更新日志**：在设置中查看版本历史与变更，离线也可阅读，并可跳转到 GitHub Release。

## 改进

- **设置弹窗**：在当前页面打开设置，保留正在查看的会话和未发送的草稿。
- **Trajectory 查找**：支持会话存在状态筛选、按最近使用或项目排序、归档标记，以及侧栏的 Open Trajectory 入口。

## 修复

- Pi 修改会话名称后，界面标题同步更新。
- 创建项目会话后正确显示分支选择器。
- 单个工具调用一次点击即可展开。
- 修复 New Chat 导航、工作区恢复与聊天样式的一致性问题。
- 打开空的浏览器或终端面板时，不再自动创建实例，改为按需显式创建。

## 安装与升级

本次提供 **macOS Apple Silicon（ARM64）** 安装包，最低支持 macOS 12。

**v0.0.1 用户需要手动下载安装一次 v0.0.2**：旧版本尚无应用内更新能力。安装本版后，后续升级可在 **Settings → About & Updates** 中完成。

下载 `PiGUI-0.0.2-arm64.dmg`，打开后将 PiGUI 拖入 Applications。ZIP、blockmap 与 `latest-mac.yml` 用于自动更新；`SHA256SUMS.txt` 包含 DMG 和 ZIP 的 SHA-256 校验值。

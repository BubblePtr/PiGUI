# Pace 0.0.7

发布日期：2026-09-12

## 改进

- Sidebar、Header 与 Settings 分类导航接入动画图标，悬停时播放一轮；触屏、禁用与减少动态效果状态下保持静态。
- 两栏 Header 对齐并贯通分隔线：Trajectory 标题与刷新操作收进左栏标题，右栏显示所选会话标题与项目；会话列表分隔、费用层级与未选中空态进一步简化。
- 侧栏操作按钮仅以图标颜色表达 hover，不再叠加背景、阴影或缩放。

## 修复

- 查看已完成会话时，进行中的会话后台事件不再抢占 Live Chat；切走后迟到的追问、stop、steer 等提交也不再回写已离开的会话视图。
- 原版扩展的后台 runner（如 pi-subagents 的 `async: true`）现在通过系统已有的 Node.js 22.19+ 启动；预检展示检测到的 Node 路径与版本或修复说明，缺失 Node 不影响普通 Pi 会话。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.7-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。

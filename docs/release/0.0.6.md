# Pace 0.0.6

发布日期：2026-09-11

## 改进

- 会话列表按最近一次发送消息的时间排序，不再按运行状态分组；刚聊过的会话始终排在前面。
- 简化会话列表头部，去掉列表边缘的淡出遮罩。

## 修复

- 修复过期投影回写会话状态的问题：已完成的工具不再被错误地恢复为运行中，工具结果不会被覆盖。
- 限制会话标题最大宽度，长标题不再覆盖 Dock 区域。
- 新建会话的后台创建事件不再串入新草稿，草稿保持干净状态。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.6-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。

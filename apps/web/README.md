# @pace/web (planned)

Thin browser client for Pace. Renders the same FSD UI as `@pace/desktop`, but
connects to a remote `@pace/server` over the WebSocket transport instead of a
local backend — a browser cannot spawn `pi` or read `~/.pi/agent`.

Not yet implemented. See [ADR-0015](../../docs/adr/0015-multi-app-monorepo.md).
